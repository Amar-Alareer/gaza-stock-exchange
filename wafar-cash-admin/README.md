# وفر كاش - لوحة التحكم الإدارية (Wafar Cash Admin)

تطبيق Vue.js 3 يحتوي على ثلاث واجهات رئيسية للوحة تحكم إدارية بالكامل باللغة العربية (RTL).

## هيكل المشروع

```
wafar-cash-admin/
├── index.html
├── package.json
├── vite.config.js
├── src/
│   ├── main.js                 # نقطة الدخول الرئيسية
│   ├── App.vue                 # المكوّن الجذري
│   ├── router/
│   │   └── router.js           # مسارات التنقل بين الواجهات الثلاث
│   ├── assets/
│   │   └── styles.css          # الأنماط العامة وألوان الهوية البصرية
│   ├── components/
│   │   ├── WafarLogo.vue       # شعار وفر كاش القابل لإعادة الاستخدام
│   │   ├── AdminSidebar.vue    # الشريط الجانبي للتنقل
│   │   └── AdminHeader.vue     # ترويسة لوحة التحكم (بحث + ملف المستخدم)
│   └── views/
│       ├── AdminLogin.vue      # الواجهة 1: تسجيل دخول المسؤول (/login)
│       ├── AdminDashboard.vue  # الواجهة 2: لوحة التحكم الرئيسية (/dashboard)
│       └── ProfileSettings.vue # الواجهة 3: إعدادات الملف الشخصي (/profile)
```

## التشغيل محلياً

```bash
npm install
npm run dev
```

سيعمل التطبيق افتراضياً على `http://localhost:5173`، ويعيد التوجيه تلقائياً من `/` إلى `/login`.

## مسارات التنقل (Routes)

| المسار         | الواجهة                    |
|----------------|-----------------------------|
| `/login`       | تسجيل دخول المسؤول          |
| `/dashboard`   | لوحة التحكم الرئيسية        |
| `/profile`     | إعدادات الملف الشخصي        |

من صفحة تسجيل الدخول، الضغط على "تسجيل دخول كآدمن" ينقلك إلى `/dashboard`. من الترويسة يمكن الوصول لصفحة الملف الشخصي عبر النقر على اسم المستخدم/الصورة، وزر "تسجيل الخروج" يعيدك إلى صفحة الدخول.

## ملاحظات تصميمية

- الهوية البصرية: أخضر داكن (`#0f3d1f`) وأخضر فاتح لامع (`#22a83e`) على خلفية بيضاء/رمادية فاتحة.
- الخط المستخدم: **Tajawal** (خط عربي عصري من Google Fonts).
- التخطيط بالكامل من اليمين لليسار (`dir="rtl"`).
- حقل "رمز الأمان من الـ backend" في صفحة الإعدادات هو حقل للقراءة فقط (`readonly`) فقط لغرض العرض التوضيحي، ولا يجب أن يُعرض فعلياً لأي مستخدم في تطبيق إنتاجي حقيقي.
